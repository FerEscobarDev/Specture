# Design System — Archivador

## Tokens
- `--color-primary: #1f4e79` · `--color-surface: #ffffff` · `--color-danger: #b00020`
- `--space-2: 8px` · `--space-4: 16px` · `--radius: 6px`
- Tipografía: Inter, 14px base.

## Componentes
- `Table` (filas con nombre, tipo, tamaño, fecha) · `Button` (primary / danger) · `EmptyState`.

## Reglas de marca
- Sin colores fuera de los tokens. Estados de error siempre con `--color-danger` y texto.
